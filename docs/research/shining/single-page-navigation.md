# 단일 페이지 탐색

- 메뉴는 ABOUT, BUSINESS, PRODUCT, CONTACT의 실제 섹션만 유지한다.
- 별도 회사 연혁·조직도·갤러리·게시판 메뉴를 제거했다.
- 제품 소식은 페이지 안에서 전문을 읽을 수 있는 카드로 표시한다.
- 사업·제품 상담은 문의 섹션으로, 문의 확인은 하단 이메일 안내로 연결한다.
- 이메일은 페이지에 표시하고 복사 버튼을 제공한다.
- 로고·푸터를 포함한 모든 링크는 현재 문서의 앵커다.
- 고정 헤더를 고려한 앵커 여백과 모바일 메뉴 선택 후 닫힘을 적용했다.
